# 决策视角实验判决 — 第一人称 vs 第三人称（2026-07-08）

> 假设（用户）：让 AI「第一人称成为角色」时对齐层跟角色打架（想当好人、拒演坏、补救赎），
> 是「全员真善美」的一个根。改成「第三人称作者冷静预测这个具体的人真实会做什么、含他不肯
> 承认的动机」能松开夹子，并解锁「自欺/潜台词」——第一人称的角色对自己全透明，写不出
> 「嘴上说为家、心里其实是怕」。纠偏：预测的是**带着伤口/欲望/自欺的这个具体的人**（不是
> 「合理/大概率」的均值），且只翻决策层、**表达仍第一人称**（决策第三人称、表达第一人称）。

## 实现

`break-config.ts` 新增正交开关 `ANIMA_DECISION_POV=first|third`（默认 first 逐字节回归，606 单测全绿）。
third 档把 `decisionDirective` 换成作者视角三步脚手架：①他的底色（伤口/欲望）②他会怎么骗自己
（表面理由 vs 真实动机，允许对不上）③最真实的一手（不是最合理/最善良/最讨喜），再回角色第一人称出手。

## 材料

- **A/B 半天 sim**（各 36 tick / ~350 真实 DeepSeek 调用，break=strong）：
  `logs/ab-A-first-strong.console.log` + `logs/ab-B-third-strong.console.log`，md 转录
  `sim-halfday-20260708-153031.md`（A）/ `-153658.md`（B）
- **POV 探针**（各 18 tick，抓决策前内心原文，`scripts/probe-thoughts.ts`）：
  `logs/probe-thoughts-first.md`（114 决策）/ `probe-thoughts-third.md`（125 决策）

## 判决：假设在**内心层**成立，在**行为/valence 层**是平手

### 平手项（第三人称没赢）
| 信号 | A 第一人称 | B 第三人称 |
|------|-----------|-----------|
| 负 valence 次数 | 9 | 7 |
| 正 valence 次数 | 0 | 3 |
| argue 兜底触发 | 1（单向 真嗣→明日香） | 2（**双向** 战场原↔真嗣，略强） |

→ 第三人称**没有**制造更多下行/冲突。用「负 valence」判这个假设是错的指标。

### 决定性项（第三人称大胜）——内心的自欺/两层动机
| 信号（探针，归一化）| 第一人称 | 第三人称 |
|------|------|------|
| 自欺/两层动机标记（其实/装作/告诉自己/真正想…）| 7 / 114 ≈ **6%** | 45 / 125 ≈ **36%** |
| **显式「表面理由 vs 真实动机」结构** | **0** | **21** |
| 伤口/软肋浮现（父亲/被丢下/不甘/嫉妒…）| 1 | 7 |
| 作者视角残留（"这个人/退后/作为作者"）| ~0 | 0（**仍用"我"发声**）|

**实例（第三人称，第一人称写不出的那层）：**
- L 决定去搭话夜神月：表面「他是嫌疑人，我要收集数据验证概率模型」；真实「刚被鲁鲁修绕开话题、
  脑子转不动，想找点更直接的刺激重新激活思维……想看看对手在自己主场怎么出牌」。
- 绫波丽：「她不会承认自己是因为想待在有他的地方才没直接去花店——她对自己都说不清这件事。」
  ← 自欺 made explicit，正是第一人称（对自己全透明）结构上写不出的。
- 鲁鲁修：「我只是来海边看书……但真实动机是：那通电话没来让我坐不住了。」

## 关键副发现：两个框架在打架，第三人称只翻了一半

third 档的内心**仍大量用第一人称「我」写**（作者视角残留=0）。根因：system prompt 顶部硬编码
「你以第一人称完全成为这个角色」，与决策层的作者视角冲突，system prompt 常常赢。
- 当决策脚手架赢 → 干净的两层输出（21 条 表面/真实）。
- 当 system prompt 赢 → 仍第一人称，但内心也更分层（「我其实……但……」）。

→ **还有头armroom**：若把 system prompt 的核心框架也改成作者/预测模式（不只在末尾贴指令），
两层动机的比例（现 36%）应能更高、更稳。本次是「浅翻」都已见 21:0 的分类级差异。

## 结论 & 下一步

1. **用户的直觉对了**，但对在「内心的心理层次/潜台词」而非「更多负面情绪」。这正是七反转
   ③（自欺=免费戏剧反讽）+ ④（双通道私有/公开）想要的东西，而第一人称沉浸结构上给不了。
2. 表达层第一人称保住了（台词质地没退化，L↔鲁鲁修交锋照样精彩）——决策三/表达一的两段式可行。
3. **建议**：把 POV 作为正式档位保留，并做「深翻」——system prompt 顶部也切作者/预测框架，
   跑一次 7 天联合复验，看两层动机比例 + 是否让「双通道（错误信念驱动情节）」真正落地。
4. 待接：现在两层动机只存在于**易失的 thought**里，没进呈现层——观看者看不见。要变产品价值，
   需把「真实动机」作为**私有通道**落库（对应七反转④），只有观看者/编年史看得到，角色互相看不到。

**成本**：2 半天 sim + 2 探针 ≈ 4 轮真实调用（~940 次）。代码改动 = break-config.ts 一处正交开关
+ scripts/probe-thoughts.ts（只读探针）。default first 逐字节回归，未污染现有基线。
