# Anima Town — Godot 前端（观看窗口）

Anima 的可视化前端：消费后端 WebSocket，把 AI 角色渲染成**日式 RPG 像素小镇**里走动的精灵。
**后端零改动**——Godot 只是又一个 WS 客户端（与 `web/` HTML 面板并存）。

- 完整设计与分期：[../PLAN-game-frontend.md](../PLAN-game-frontend.md)
- 引擎：Godot **4.6**（用 `WebSocketPeer`、`TileMapLayer`）
- 后端消息定义：`../src/api/server.ts`
- 美术：**Ninja Adventure**（CC0）+ 缝合像素字体（OFL），来源与许可见 [assets/README.md](assets/README.md)

## 当前阶段：世界 2.0（P0~P3 完整游戏化）

- **P0** 数据流：连后端收 `snapshot`/`tick`
- **P1 大地图**：72x40 瓦片小镇，树墙边界 + 草地/沙滩/海面/土路/池塘，

- **P2 有灵魂**：想法/对话气泡（JRPG 样式）+ 情绪 emote + 动作标签 + 点角色弹详情（像素头像，离线也可用）
- **P3 完整游戏化（2026-07-03）**：
  - **室内场景 ×13**：咖啡馆/酒吧/图书馆/杂货店/面包坊/花店/7 栋住宅，各有墙面/地板/家具

  - **寻路碰撞**：AStarGrid2D 网格寻路，建筑/树木/水面/家具是障碍，角色沿路网绕行
  - **相机系统**：拖拽平移 + 滚轮缩放 + 点角色跟随（跟随对象进出室内时镜头自动切换）
  - **昼夜氛围**：按 `formattedTime` 时段词染色，夜里暖窗光/灯笼辉光；室内始终亮灯
  - **BGM**：白天 Calm Village / 夜晚 Chill（Ninja Adventure 音乐，CC0），M 键开关
  - **天气特效**：rainy/stormy 雨幕、snowy 雪花、cloudy 压暗（跟随后端 weather 字段，中文显示）

  - beat 剧情横幅（JRPG 弹窗）
  - **P4 控制**：调速（暂停/1x/2x/5x，`speed_changed` 回执高亮）+ **叙事干预面板**
    （N 键或右上角"叙事"按钮：塞纸条/散布流言/注入事件/推进导演，走 HTTP，离线禁用发送）
  - **行为可视化**：工具调用 → 画面表现——对话/八卦/安慰/吵架/送礼时**说话者凑到对方身边、
    双方面对面**；送礼飞小包裹 + 对方冒爱心；吵架双方怒/心碎 emote；睡觉冒困、发呆冒"…"
  - **剧本适配**：mygo-seaside 5 角色皮肤已配；未知 `home_*` 地点自动复用默认七栋住宅的
    空位（含室内/徽章），所以大多数海边小镇类剧本零配置可用
- **世界 2.5「完整日式 RPG」（2026-07-05）**——补齐三缺口，全是消费后端已下发、此前被前端丢弃的数据：

  - **走路取代瞬移**：室内区在地图断裂的另一片区域 → 跨空间用「走到门→淡出→另一侧门口现身→走进」

## 跑起来

**方式 A — 离线预览（不用后端，看美术）**
1. Godot 4.6 打开本 `godot/` 目录
2. `F5` 运行 → 3 秒后自动用假数据渲染小镇（零 LLM 成本），1.4 秒后有角色走动/进店演示

**方式 B — 接真后端（看活的模拟）**
1. 仓库根 `pnpm dev`（默认 `http://localhost:3001`）
2. Godot `F5` → 角色随真实剧情移动、冒真实内心独白/对话
3. 看完停后端：**`lsof -ti:3001 | xargs kill -9`**（别用 pkill，匹配不到会残留偷跑烧 token）

**截图（给开发看效果）**：`godot --path . -- --shot [--day] [--wide] [--rain] [--room <地点id>] [--log] [--roster] [--relweb]`
→ 渲染一张 `shot.png` 后自动退出（默认夜晚广场；`--wide` 全图；`--room cafe` 咖啡馆室内；`--log` 打开生活记录）。
接真后端跑 3 分钟每 30s 存一张：`--probe`

## 操作

拖拽 = 平移相机 · 滚轮 = 缩放 · 点角色 = 跟随 + 详情面板 · 点建筑 = 进室内 ·
ESC = 关面板/返回小镇 · **Tab = 镇民状态名册** · **R = 关系网** · **L = 生活记录** · M = 音乐开关 · N = 叙事干预（塞纸条/流言/事件/推进导演）

## 生存可视化（让 AI 的生存被看见）

needs（饿/困/寂/脏/闷/急，0-100，低=差）在三处游戏化呈现，纯前端消费 tick 已下发的 `needs`：

- **镇民状态名册**（Tab / HUD「名册」按钮）：JRPG 半透明菜单，一眼看全镇 AI —— 头像 + 名字 +
  当前动作 + 饿/困 迷你血条（绿/橙/红）+ 最紧迫需求高亮标签
- **头顶告警徽章**：需求跌破阈值时角色头顶挂「饿/困/寂…」小牌，urgent 红底脉动、moderate 橙底
- **详情面板需求条**：六条彩色血条 + 数值 + 中文标签（原来是裸数字）

截图验证：`--roster`（开名册）、`--detail <角色id>`（开详情面板）两个 flag

## 四季换装（气候系统前端）

后端 `climate.ts` 广播 `temperature` + `formattedTime` 带季节；前端据此换装：

- **季节染色**：地面/建筑按季节整体上色（春嫩绿 / 夏标准 / 秋金黄 / 冬冷白），与昼夜时段染色**相乘**
  （角色只吃时段染色，免得脸发绿）
- **季节氛围粒子**：春樱花瓣 / 秋落叶 / 冬雪絮（preprocess 预热，一开场整屏就飘满）
- **时钟显示体感温度**：如「秋 第2天 · 上午 10:00　晴 13°C」

截图验证 flag：`--spring` / `--summer` / `--autumn` / `--winter`（配 `--day` / `--wide`），
参考图 `docs/shot_climate_autumn.png`、`docs/shot_climate_winter.png`

## 经济可视化（生计压力看得见）

后端 `economy.ts` 有了生计压力（每日房租）+ 财务体感，前端据此呈现：

- **名册金币**：每行显示金币数，按财务档上色（红=拮据/揭不开锅、橙=手头紧、绿=宽裕）
- **详情钱包行**：「钱包 42 金币 · 手头紧」
- **头顶飘金币**：挣钱（绿 +N）/ 花钱·房租（红 −N），diff 上一 tick 的 gold 自动触发

参考图 `docs/shot_economy_roster.png`、`docs/shot_economy_detail.png`

## 关系网可视化（社交脉络看得见）

**R 键 / HUD「关系」按钮** 打开：全镇角色沿圆环排布，两两之间的关系画成连线——

- **颜色 = 关系类型**：挚友/好友绿、点头之交灰、宿敌红、暧昧/恋人粉
- **粗细 = 强度**：亲密度/敌对越深线越粗
- **bond 身份**：恋人/前任/同事/室友/师徒/宿敌 在连线中点标注

纯前端，消费 tick 已下发的 `relationships[]`。截图 flag：`--relweb`，参考图 `docs/shot_relationweb.png`

## 素材坐标经验（重要）

图集里建筑/道具是紧挨着排的，**任何新 region 都必须先裁片放大人工确认边界再用**
（本项目踩过的坑：杂货店实际 4 格宽、面包坊在 23..25 不是 22..24、面包篮是 2x2 大图的碎块、
石柱是 1x3 含底座、完整圆岩在 (13,8,2,2) 而不是石堆中间）。
检查方法见仓库根 `PLAN-game-frontend.md` 或直接用 python PIL 裁片放大标注。

## 换剧本 / 加角色皮肤

- 已知 7 角色的皮肤映射在 `Main.gd` 的 `CHAR_SKINS`；未知角色自动从 `FALLBACK_SKINS` 按 id 哈希取
- 未知地点自动沿沙滩排开（不至于崩，但建议给新剧本在 `Town.gd` 的 `LAYOUT` 补布局）
- 加皮肤：从 Ninja Adventure 完整包复制 `<角色>/{Idle,Walk,Faceset}.png` 到
  `assets/ninja_adventure/characters/<皮肤名>/`（Idle 64x16、Walk 64x64，列=下/上/左/右）
